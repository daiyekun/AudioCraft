# 项目说明

项目主要是为了完成把awb转换程mp3格式。需要实现以下几个要求：

1、可以批量转换文件。

2、awb和mp3可以使用下拉框进行选择，方便未来其他格式转换

3、可以拖拽文件到界面实现上传。转换成功以后提示成功。

4、可以通过按钮打开mp3目标目录。可以点击另存为某一个目录。

5、点击按钮进行转换。可以看到每一个文件转换进度。都转换成功提示成功。如果有个别失败给出提示。并记录对应日志到logs里面

# 技术栈

1、使用WPF进行设计。

2、居于希望能够安装到windows10和windows11

3、界面需要要有一定科技感。

4、使用ffmpeg.exe进行转换。文件我已经放置到项目tools/
